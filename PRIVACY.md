# Política de Privacidad de OnOffEther

**Última actualización: Octubre 2026**

## 1. Introducción

OnOffEther ("la Aplicación") es una herramienta de Windows que permite activar y desactivar la conexión Ethernet con un solo clic. Esta política de privacidad explica cómo manejamos tus datos cuando usas OnOffEther.

## 2. Datos que Recopilamos

OnOffEther **NO recopila, almacena ni transmite datos personales**. La aplicación es completamente funcional sin enviar información a servidores externos.

La Aplicación solo almacena localmente tus preferencias:
- **Tema elegido** (claro u oscuro)
- **Idioma preferido** (English, Español, Français, Deutsch, Português)

Estas preferencias se guardan únicamente en tu dispositivo.

## 3. Conexiones de Red

OnOffEther **no realiza conexiones de red por su cuenta**. La Aplicación no se conecta a internet, no descarga actualizaciones automáticas y no contiene servicios en segundo plano que envíen datos.

La única funcionalidad de red de OnOffEther es controlar el adaptador Ethernet de tu dispositivo a través de las API estándar de Windows.

## 4. Permisos Requeridos

OnOffEther requiere derechos de administrador para:
- Activar y desactivar el adaptador Ethernet
- Registrar tareas programadas de Windows

Estos permisos se solicitan una única vez durante la instalación.

## 5. Información del Sistema

OnOffEther accede a información mínima del sistema:
- Estado del adaptador Ethernet
- Configuración del Administrador de Dispositivos

Esta información se utiliza **únicamente para el funcionamiento de la Aplicación** en tu dispositivo local.

## 6. Datos de Terceros

OnOffEther no integra servicios de terceros, no incluye rastreadores analíticos ni código de publicidad.

## 7. Seguridad

Dado que OnOffEther no recopila ni transmite datos personales, la seguridad de datos no es una preocupación típica. Sin embargo:
- Las preferencias se almacenan en tu dispositivo de forma local
- No se establecen conexiones externas
- El código fuente está disponible públicamente en GitHub para revisión independiente

## 8. Cambios en Esta Política

Nos reservamos el derecho de actualizar esta política de privacidad en cualquier momento. Los cambios significativos se comunicarán a través de las notas de la versión de la aplicación.
