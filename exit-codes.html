Installer return codes

Applies to OnOffEther 1.5.0 and later · Last updated: 2 October 2026

This page documents the command line and the exit codes of OnOffEther-Setup-x.y.z.exe, for unattended deployment and for store distribution.

Return codes

CodeMeaningDescription
0SuccessThe application was installed. No reboot is required at any point.
1602Cancelled by the userThe setup window was closed without installing. Only happens in interactive mode.
1603Fatal error during installationFiles could not be copied, or the scheduled tasks could not be registered. Nothing is left half installed.
1925Administrator rights requiredA silent install was started without elevation. Run the installer elevated and it will succeed.

No other values are returned. There is no reboot-required code, because installing or removing the app never needs one.

Silent install

SwitchEffect
/SInstalls with no user interface. /silent, /quiet, /q and /verysilent are accepted as synonyms.
/lang=xxSets the default language of the application: en, es, fr, de or pt. Without it, English is used. Each user can change it later inside the app.
/desktopAlso creates a desktop shortcut. Omitted, only a Start menu shortcut is created.

Example:

OnOffEther-Setup-1.5.0.exe /S /lang=en

Silent uninstall

"C:\Program Files\OnOffEther\OnOffEther.exe" /uninstall /silent

The same command is published in the registry as QuietUninstallString, under
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\OnOffEther.

Uninstalling returns the same codes as above. If the wired connection is disabled at that moment, it is enabled again before anything is removed, so the machine is never left without network access.

Detection

Once installed, the app can be detected through its entry in Programs and Features:

Registry keyHKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\OnOffEther
DisplayNameOnOffEther
PublisherDivolandia Labs
DisplayVersion1.5.0
Install locationC:\Program Files\OnOffEther

What the installer changes

  • Copies OnOffEther.exe and two icon files to C:\Program Files\OnOffEther.
  • Registers two scheduled tasks, OnOffEther_On and OnOffEther_Off, which switch the Ethernet adapter with elevated rights so the app never shows a permission prompt.
  • Creates a Start menu shortcut, and a desktop one with /desktop.
  • Writes the uninstall entry and the default language under HKLM\SOFTWARE\OnOffEther.

Uninstalling removes every one of those items.
